# Word & Letter Counter

This Python program counts words (with length ≥ 2), letters, and the frequency of each word in a sentence.

## Features
- Count the total number of words (length ≥ 2)
- Count the total number of letters
- Count the frequency of each word
- Supports multiple sentences in one run

## How to Run
1. Make sure you have Python installed
2. Run the script in terminal or command prompt:
3. Type a sentence and press Enter
4. Type `ex` to exit the program

## Notes
- Only alphabetic characters are counted as letters
- Only words with length ≥ 2 are counted

## Example
Input: "Hi Hi World"  
Output:  
Word count: 3  
Letter count: 10  
Word frequencies:  
Hi: 2  
World: 1
